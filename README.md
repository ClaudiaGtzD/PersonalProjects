# Portafolio de proyectos de datos 📊

¡Hola! Soy **Claudia Lissette Gutiérrez Díaz**, Licenciada en Ciencias Computacionales y Maestra en Ciencia de Datos por la Universidad Autónoma de Nuevo León.

Cuento con más de 11 años de experiencia en análisis de datos, Business Intelligence, SQL Server, automatización de procesos y desarrollo de soluciones orientadas al negocio.

Este repositorio reúne proyectos desarrollados durante mi **Maestría en Ciencia de Datos**, además de ejercicios y casos de estudio relacionados con análisis, modelado, visualización y automatización.

---

## Sobre este repositorio

El objetivo de este espacio es documentar de forma clara:

- El problema que se busca resolver.
- El proceso de obtención y preparación de datos.
- Las técnicas y modelos utilizados.
- Los resultados obtenidos.
- Las conclusiones, limitaciones y posibles mejoras.

Cada proyecto tendrá su propia carpeta y un README con una explicación más detallada.
